**App Name:** My Task List

**Author:** Jonathan Pactong Lin

## Description

A website to create your own tasks, rank the priorities, and be able to mark them as complete or delete them. Tasks are not saved on refresh

## How To Run

Have all 3 files in a folder. This includes: "script.js", "style.css", and "index.html". readme is not needed. then launch index.html
